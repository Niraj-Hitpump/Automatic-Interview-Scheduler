# 🤖 Automatic Interview Scheduler — Smart Slot Booking System

A production-ready Interview Scheduling Application built using **Java Spring Boot**, **Next.js (React)**, and **MySQL** that enables seamless booking between candidates and interviewers.

It automates availability → slot generation → booking → completion tracking, while ensuring race-condition safety and real-time updates across both user dashboards.

> 🔥 Designed for scalable interview management with clean architecture, strong validations & modern UI!

## 🚀 Key Features

- 🧑‍💼 Interviewer can add weekly availability  
- 📆 System auto-generates slots for next **2 weeks**
- 🎯 Candidate can book **only 1 active interview**
- 👥 Weekly capacity support (multiple candidates per week)
- ⭐ Real-time status updates between dashboards
- ❌ Cancel / ✔ Complete interview updates
- 🔄 Pagination for large number of slots
- 🔐 Secure login (JWT Authentication)
- ⚠ Strong race-condition prevention with DB checks
- 🎨 Clean & beautiful UI with role-based screens
